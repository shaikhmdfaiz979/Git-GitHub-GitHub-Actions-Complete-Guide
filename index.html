Create your first repository

BEGINNER

A repository is a project folder that Git tracks. Initialise Git to start recording your project's history.

Bash / Terminal 
mkdir my-project
cd my-project
git init
✦

Remember: `git init` creates the local Git repository. It does not upload anything to GitHub.

LESS MANUAL WORK, MORE BUILDING

Automate with GitHub Actions.

Make GitHub run a workflow for you. Start with a small workflow that prints a message when you push to the main branch.

↥
Push codeYou update GitHub
→
⚡
Workflow startsAn event triggers it
→
✓
Job runsCommands execute
hello.yml.github / workflows
name: Hello GitHub Actions

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read

jobs:
  hello:
    runs-on: ubuntu-latest
    steps:
      - name: Say hello
        run: echo "Hello from GitHub Actions!"
✓ Ready to customiseYAML workflow

Save this file as .github/workflows/hello.yml, commit it, and push it to GitHub. Then open your repository's Actions tab to see the run.

TAKE IT LIVE

From a folder to a live website.

GitHub Pages can host static websites made with HTML, CSS, and browser-side JavaScript. Follow these steps to publish a simple site.

1
Create index.html

Add the content of your website.

2
Push it to GitHub

Commit your files and push to your repository.

3
Enable Pages

Open Settings → Pages and choose your publishing source.

4
Share your URL

Wait for deployment, then open the URL shown in Pages settings.
